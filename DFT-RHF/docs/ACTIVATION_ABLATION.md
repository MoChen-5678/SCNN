# RMF Hamiltonian 网络激活函数对照

在相同 PKDD O16、严格 `(S,V0,V3,VC)` 通道、完整作用量、`lambda=20`、学习率和随机种子下，
比较 5000 轮 SiLU 与残差 SwiGLU。SCF 仅用于训练后评价。

## 实现

- `silu`：三层 SiLU MLP，线性输出；
- `swiglu`：两层残差 `W_v x * SiLU(W_g x)` 门控块，门偏置初始化为 1，线性输出；
- 两者都不在势输出端使用有界激活；
- 两者都严格输出物理分量 `(S,V0,V3,VC)` 后组装 Dirac 通道。

## 结果

| 指标 | SiLU | 残差 SwiGLU |
|---|---:|---:|
| 训练参数量 | 约 7.6 万 | 151,300 |
| 最低记录 E/A (MeV) | -7.23914 | -7.26579 |
| 最佳广义梯度 checkpoint E/A (MeV) | -6.95328 | -6.95090 |
| 最佳 checkpoint 占据态 MAE (MeV) | 2.7243 | 2.4613 |
| `VPS_n` RMSE (fm^-1) | 0.01756 | 0.02544 |
| `VMS_n` RMSE (fm^-1) | 0.17133 | 0.17478 |
| `VPS_p` RMSE (fm^-1) | 0.01720 | 0.02830 |
| `VMS_p` RMSE (fm^-1) | 0.17187 | 0.17806 |

SwiGLU 前 100 轮更快，但长训练多次进入正能量、超大半径支，最终势误差没有改善。该结果不支持
用 SwiGLU 替换默认 SiLU。

## 结论

当前误差不是网络缺少复杂激活，而是 PRL 广义梯度中
`grad_E` 与 `lambda*(H-H_tilde)` 可以互相抵消。只监控两者之和会选中一个既非能量驻点、也非严格
固定点的状态。下一步应分别控制两个残差，采用增广拉格朗日、自适应 `lambda` 或分阶段优化。

不建议在缺少变分或谱性质论证时发明新的“物理激活函数”。如果后续测试自适应 SiLU，验收必须同时
满足：平滑高阶导数、线性无界输出、无额外振荡、跨核素稳定，以及两个物理残差分别下降。
