# DPL-RMF 物理约束与 PRL 实现偏差分析报告

## 1. 结论

当前误差的主要原因不是激活函数，也不是训练轮数不足，而是网络输出空间仍大于严格的
PKDD-RMF 物理空间。

刚才选出的旧结果 `complete_action_O16_gpu_500` 虽然给出
`E/A=-7.291014 MeV`，与 Core-1204 的无质心结果 `-7.315856 MeV` 只差
`0.024842 MeV`，但它不是可信的严格 RMF 解。该结果允许中子和质子拥有不同标量自能：

```text
RMS(S_n-S_p) = 8.8113 MeV
max|S_n-S_p| = 37.9017 MeV
```

而 PKDD-RMF 中二者必须严格共享同一个 `S=g_sigma sigma`。因此，旧结果的能量接近主要包含
非物理通道间的误差抵消，不能作为模型正确性的证据。

当前严格版已经修复共享标量场、Hermiticity、轨道归一和离散场作用量，但仍有一个更深层的
问题：网络直接输出任意平滑的 `(S,V0,V3,VC)`，而不是输出由核子密度经过书中场方程生成的
物理场。场方程只通过 `H-H_tilde` 梯度软约束网络，没有成为网络前向结构的一部分。因此物理
方程存在于后端，却没有完整嵌入网络表示空间。

## 2. 依据与对照标准

本报告只采用以下本地文献和程序数据：

1. `PhysRevLett.133.076401(1).pdf`；
2. `核物理(1).pdf` 第 1、3 章，特别是式 (3.42)-(3.48)；
3. `张颖-Wang_2025_Chinese_Phys._C_49_014106.pdf`；
4. Core-1204 的 PKDD/16O 结果；
5. 当前 DPL 输出和训练诊断。

PRL 的核心流程是：

```text
H_theta -> rho -> n -> E[H_theta]
grad_H E + lambda (H_theta-H_tilde)
```

论文明确要求 Hamiltonian 表示满足基本结构条件，例如 Hermiticity；能量梯度负责过滤非物理
高能噪声，重建项负责确定能量看不到的未占据空间。论文还先验证可微 DFT 与标准 SCF 一致，
再验证直接变分，最后才接神经网络。

核物理书给出的 RMF 场不是四个独立函数，而是由同一组占据轨道产生：

```text
rho_s, rho_b, rho_b3, rho_p
  -> g_sigma(rho_b), g_omega(rho_b), g_rho(rho_b)
  -> sigma, omega, rho, A                    (3.42)-(3.45)
  -> Sigma_R                                 (3.46)
  -> Sigma_+^tau, Sigma_-^tau                (3.47)-(3.48)
```

这条因果链定义了 PKDD-RMF 的物理 Hamiltonian 流形。

## 3. 已发现的错误

### 3.1 旧版接近能量的数据违反硬通道约束

旧结果的网络实际上能够形成彼此独立的中子、质子上下通道。由输出反演得到：

| 量 | 旧 DPL | Core |
|---|---:|---:|
| `RMS(S_n-S_p)` | `8.8113 MeV` | `1.8e-5 MeV` |
| `max|S_n-S_p|` | `37.9017 MeV` | `1.8e-5 MeV` |

同一结果中，网络 Hamiltonian 与密度重建 Hamiltonian 的物理分量误差为：

| 分量 | RMS | 最大误差 |
|---|---:|---:|
| `S_n` | `10.08 MeV` | `32.25 MeV` |
| `S_p` | `8.84 MeV` | `42.36 MeV` |
| `V_n` | `9.97 MeV` | `33.04 MeV` |
| `V_p` | `8.76 MeV` | `40.97 MeV` |

所以旧结果只能称为数值上接近能量的非物理解。

### 3.2 当前网络只硬编码了通道代数，没有硬编码场方程

当前 `LocalHamiltonianNet` 输出四个任意 MLP 函数：

```text
(S,V0,V3,VC) = initial + scale * envelope * MLP(r,N,Z,A)
```

随后按式 (3.48) 组装四个 Dirac 通道。这能严格保证：

- 中子和质子共享 `S`；
- `V3` 对中子、质子反号；
- `VC` 只进入质子通道；
- 中子、质子质量移位分别使用 `M_n` 和 `M_p`。

但它不能保证：

- `S=g_sigma(rho_b)sigma`；
- `V0=g_omega(rho_b)omega+Sigma_R`；
- `V3=g_rho(rho_b)rho`；
- `VC=eA`；
- 四个场满足式 (3.42)-(3.45)；
- `Sigma_R` 必须由同一密度和同一场按式 (3.46) 生成。

这些条件目前全部依赖 `H-H_tilde` 软重建梯度。网络在训练中仍可离开物理场流形。

### 3.3 当前“场方程达到机器精度”检查了错误的对象

后端先从网络 Hamiltonian 求轨道和密度，再精确解离散场方程得到 `rebuilt_fields`。诊断中的
`weak_el_sigma/omega/rho/coul` 检查的是这些重建场，不是网络输出反演出的场。

因此 `weak_el ~ 1e-13` 只证明线性求解器正确，不能证明网络 Hamiltonian 满足场方程。当前严格
版在最佳轮次仍有：

```text
RMS(H-H_tilde) in S channel  = 20.09 MeV
RMS(H-H_tilde) in V channel  = 13.86-13.94 MeV
```

最大误差集中在核中心，达到 `132-140 MeV`。这与 `E/A=-11.561 MeV` 的过绑定直接一致。

### 3.4 球对称场的中心边界没有嵌入网络

球对称标量函数必须满足中心正则条件：

```text
dS/dr|_0 = dV0/dr|_0 = dV3/dr|_0 = dVC/dr|_0 = 0
```

当前包络 `(1-r/R)^2` 只控制盒子外端，不控制原点导数。MLP 对 `r` 的一般输出在原点具有非零
斜率。当前严格版第一物理网格区间上的斜率约为：

```text
dS/dr  = +230 MeV/fm
dV/dr  = -186 MeV/fm
```

这不是球对称正则场，并且正是中心 `H-H_tilde` 误差最大的原因。已有测试只检查轨道的原点
幂律，没有检查网络势场的中心 Neumann 条件。

### 3.5 ADF 实现没有严格复现张颖论文的奇偶交替规则

张颖论文明确指出：大、小分量应根据各自奇偶性交替使用前向和后向 ADF，以同时保证
Hamiltonian Hermiticity、边界行为并消除假态。

当前实现构造一个统一的前向七点导数矩阵，只在右侧因网格不足改用后向行，然后用矩阵转置
配对获得 Hermiticity。这不等价于论文按 `G/F` 奇偶性选择前向/后向 ADF 的规则。

当前测试只验证七点系数的多项式矩条件和矩阵 Hermiticity，没有执行论文要求的假态基准：

- 与相同盒边界的 shooting 单粒子谱比较；
- 检查每个 `kappa` 块的节点数；
- 检查物理态和假态是否成对出现；
- 检查奇偶分量在盒边界的行为。

所以“谱残差很小”只代表离散矩阵本征方程解得准确，不代表该离散矩阵就是论文中的正确
Dirac 算符。

### 3.6 占据态选择不是严格的核基态占据规则

核物理书要求同类核子能级按能量从低到高占据。当前实现先使用固定壳层表确定需要哪些
`(principal,kappa)`，再根据与 Woods-Saxon 参考轨道的重叠选择本征态。它没有在所有 `kappa`
块之间执行全局按能量填充，也没有把节点数作为严格量子数约束。

这对预设闭壳层 16O 通常可工作，但在训练发生能级交叉或推广到其他核时，不保证得到最低能量
Slater 行列式。离散选择还会导致梯度不连续和训练分支跳变。

### 3.7 PRL 重建梯度使用了错误的坐标度量

网络的独立自由度是 `(S,V0,V3,VC)`，训练器却在
`(VPS_n,VMS_n,VPS_p,VMS_p)` 空间中对 `H-H_tilde` 分通道缩放。四个 Dirac 通道不是独立变量，
且 `V0,V3,VC` 在四通道中的映射具有相关性。当前逐 Dirac 通道的经验尺度不能构成物理分量
空间中的正确度量，可能使标量、等标矢量、同位旋和库仑方向受到错误权重。

正确做法应在网络实际输出的独立物理坐标上构造残差，并使用由作用量二次型或明确物理单位
定义的度量，而不是在质量平移后的上下通道上经验加权。

### 3.8 当前流程跳过了 PRL 的关键验证顺序

PRL 先证明可微 DFT 与基准 SCF 一致，然后证明直接 Hamiltonian 变分在几十步内使
`Delta H, Delta rho, Delta n, Delta E` 指数收敛，最后才训练神经网络。

当前程序直接进入单核网络训练。缺少两个隔离试验：

1. 不使用网络，直接优化完整网格上的物理分量，确认泛函梯度本身能到达正确驻点；
2. 确认该驻点与 Core 在相同物理约定和离散极限下一致。

因此目前无法区分“泛函/离散错误”和“网络参数化/优化错误”。2000 轮平台期已经证明继续增加
轮数不能替代这两个验证。

### 3.9 当前网络不是 PRL 所展示的可迁移模型

PRL 使用满足空间对称性的等变网络，将结构映射到局域 Hamiltonian，并在多结构上训练。当前
网络为每个核重新优化四个一维 MLP；`N,Z,A` 在单次训练中是常数，不提供跨核学习信号。

球对称问题不需要 E(3) 图网络，但至少需要把球对称、同位旋对称、中心正则性和跨核条件化
写入表示层，并在多个核上共享参数。当前实现更接近“用网络参数化一次数值变分”，还不是
PRL 意义上的可迁移神经网络 DFT。

## 4. 约束分层

并非所有物理条件都能以同一种方式嵌入网络。严格实现应分三层。

### 4.1 必须由网络结构硬保证

- 球对称，只依赖 `r`；
- `S_n=S_p` 和式 (3.48) 的同位旋代数；
- `M_n != M_p` 的质量移位；
- 中心偶解析行为，所有局域场满足 `dphi/dr|_0=0`；
- massive 场在盒边衰减，库仑场具有 `Z alpha/r` 尾部；
- 场和密度的单位、符号及允许的渐近行为；
- 轨道原点幂律、盒边界、正交归一；
- 粒子数与占据简并度。

### 4.2 必须由可微物理层精确完成

- 由轨道计算 `rho_s,rho_b,rho_b3,rho_p`；
- PKDD 密度依赖耦合及其导数；
- 式 (3.42)-(3.45) 的场生成；
- 式 (3.46) 的重排项；
- 式 (3.48) 的 Hamiltonian 组装；
- Dirac 广义 Hermitian 谱分解或严格的轨道变分；
- 完整作用量、积分和自动微分。

### 4.3 只能在变分驻点满足

- `H = H_tilde[rho(H)]`；
- `delta Gamma/dH = 0`；
- 占据子空间与最终 Hamiltonian 自洽。

若要求第三层在每次纯前馈时也严格成立，就必须引入隐式固定点求解或直接参数化驻点解；这在
数学上等价于求解非线性自洽问题。PRL 的方法正是用广义梯度而不是网络结构来满足这一层。
因此“物理约束嵌入网络”应严格落实前两层，第三层由变分残差控制，不能用能量接近代替。

## 5. 建议的正确实现路径

### 第一阶段：修复物理表示层

网络不再直接自由输出四个势，而输出满足中心偶解析行为的潜变量，例如只使用
`r^2`、`N/A`、`Z/A` 和 `A` 作为输入。所有 massive 通道采用同时满足中心 Neumann 和盒边
Dirichlet 的解析包络；库仑通道分成固定的 `Z alpha/r` 尾部和满足齐次 Robin 条件的内部修正。

更严格的方案是网络输出正交占据轨道或物理源密度，随后在前向图中严格执行：

```text
network latent orbitals/sources
 -> normalized densities
 -> exact PKDD couplings
 -> exact meson/Poisson field layer
 -> exact rearrangement
 -> physical Hamiltonian
```

这样网络的每一次前向输出都位于场方程生成的 RMF Hamiltonian 空间。Dirac 驻点条件再由变分
梯度满足。此方案比“自由输出 H 再用 H-H_tilde 拉回”更符合本项目对硬物理空间的要求。

### 第二阶段：修复离散 Dirac 约束

严格实现张颖论文的奇偶交替 ADF；七点格式只能作为五点公式的高阶扩展，但必须保持同样的
前向/后向奇偶规则。建立 shooting 对照测试，逐 `kappa` 验证能量、节点数、边界和假态消失，
不能只验证矩阵本征残差。

### 第三阶段：先验证无网络直接变分

在接 MLP 前，使用同一物理表示层的网格系数直接变分。验收条件是：

- 能量梯度与重建残差同时趋近零；
- 不使用 Core 数据选模；
- 结束后与 Core 比较能量、半径、场和单粒子谱；
- 网格加密后结果稳定。

只有直接变分通过，才能证明核泛函和离散路径正确。

### 第四阶段：恢复 PRL 神经网络训练

网络只替换直接变分参数，不改变物理前向图。在独立物理分量空间构造广义梯度和残差度量；
先训练 16O，再用 `40Ca,48Ca,208Pb` 共享参数验证跨核条件化。Core 始终只用于训练后评估。

## 6. 优先级

| 优先级 | 问题 | 影响 |
|---|---|---|
| P0 | 网络势场不由密度和场方程硬生成 | 网络仍可离开 RMF 物理空间 |
| P0 | 诊断只检查重建场，不检查网络场 | 机器精度残差具有误导性 |
| P0 | 旧接近能量结果违反 `S_n=S_p` | 接近来自非物理误差抵消 |
| P1 | 网络缺少中心 Neumann 硬边界 | 核中心出现 100 MeV 量级偏差 |
| P1 | ADF 未按论文奇偶交替实现 | 假态与边界正确性尚未证明 |
| P1 | 占据态不是全局能量填充 | 能级交叉时基态和梯度不可靠 |
| P1 | 重建残差不在独立物理分量度量中 | 通道优化权重失真 |

| P2 | 单核独立训练 | 不具备 PRL 的迁移能力 |

## 7. 最终判断

当前最接近 Core 的旧数据不能保留为“最佳物理解”；它只能作为反例，说明只比较总能量会被
非物理通道抵消欺骗。当前严格版修复了部分硬约束，却仍把最关键的“密度 -> 场 -> 重排 -> H”
关系放在网络外部作为软重建目标。

下一版不应继续调激活函数或盲目增加训练轮数。首先必须改变网络前向表示，使可硬编码的核物理
约束真正限定网络输出空间；然后用无网络直接变分证明完整物理层可以到达 Core 对应驻点，最后
才恢复 PRL 神经网络优化。

## 8. 本轮修复状态

已实现：

- 参数空间改为独立物理分量 `S,V0,V3,VC`，中子/质子 Hamiltonian 只由严格通道恒等式组装；
- 强作用通道满足中心偶性和盒边界零值/零导数，库仑通道硬编码 `Z alpha/r` 尾和 Robin 条件；
- PRL 能量梯度与重构残差都在独立物理分量空间中计算；
- 默认 `direct` 模式用同一物理表示层做无网络 Chebyshev 直接变分；
- 七点 ADF 使用全盒一致的前向模板、零外部边界及严格负转置后向算符；
- 占据数由各物种候选态全局按能量填充，轨道节点和占据投影逐轮输出；
- 增加同一 SCF 势下 ADF/Fortran shooting 对照，以及能量、半径、势场和单粒子谱外部门；
- 超过 200 轮的网络训练必须读取已经通过的直接变分门文件。

仍必须由实际运行决定、不能在代码层宣称解决：

- ADF 与 shooting 的占据态能量误差是否低于 `0.5 MeV`；
- 直接变分是否同时达到内部驻点和 Core 外部盲测阈值；
- 若上述任一门失败，`physics_gate_passed=false`，此时不得把结果称为正确核物理解，也不得进入
  长网络训练。SCF 数值只用于训练结束后的门测试，不参与损失或 checkpoint 选择。

端到端两轮 O16/PKDD 冒烟验证（`/tmp/prl_repair_e2e`）给出的当前基线为：

| 指标 | 数值 | 默认阈值 | 结果 |
|---|---:|---:|---|
| 内部联合残差 | 1.000 | 0.001 | 失败 |
| `E/A` 与 Core 绝对差 | 5.5128 MeV | 0.5 MeV | 失败 |
| 物质半径绝对差 | 0.1538 fm | 0.1 fm | 失败 |
| 最大势通道相对 L2 | 0.0872 | 0.1 | 通过 |
| DPL 势下 Fortran 单粒子 MAE | 4.4639 MeV | 1.0 MeV | 失败 |
| 同一 SCF 势下 ADF/shooting MAE | 4.1940 MeV | 0.5 MeV | 失败 |

ADF 波函数与 shooting 的最小绝对重叠为 `0.9943`，占据态节点全部正确，但能量仍系统性偏低。
这说明剩余首要问题是离散 Dirac 谱的定量误差，不是增加训练轮数可以解决的问题；当前程序因此
正确关闭物理门。

### 8.1 `B1/B2` 关键修复

后续定位确认，上表的 ADF 能量偏移来自没有按论文直接构造两个非对角微分块。旧实现把积分
权重放入广义弱形式，再通过转置和整体对称化间接生成非对角块；矩阵虽数值厄米，却已不是论文
的坐标空间 ADF Hamiltonian。

现已改成逐 `kappa` 严格构造：

```text
B1 = -D_backward + kappa/r
B2 =  D_forward  + kappa/r
H  = [[V+S, B1], [B2, V-S-2M]]
```

径向大分量 `G(r)` 奇函数严格使用 forward ADF，偶函数使用 backward ADF；小分量使用相反方向。
由于 `G(r)~r^(l+1)`，这里不能直接用轨道 `l` 的奇偶性代替径向函数奇偶性。
始终满足 `-D_backward=D_forward^T`，因此
`B1=B2^T`；不再对完整 Hamiltonian 做事后对称化。Simpson 权重只用于波函数物理归一化和
径向积分，不进入坐标点本征矩阵。

在同一个 Core SCF 势上的六个 O16 占据态验证结果：

| 实现 | ADF/shooting MAE | 最大绝对误差 |
|---|---:|---:|
| 旧广义弱形式 | 4.194020 MeV | 5.159186 MeV |
